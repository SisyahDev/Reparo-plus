# 🔧 Reparos+

> Encontre profissionais com segurança.

O Reparos+ é um MVP de uma plataforma voltada para a busca e contratação
de profissionais de serviços domésticos, com foco em segurança,
transparência e praticidade.

## 📌 Sobre o projeto

O projeto surgiu a partir de um problema comum na contratação de
profissionais para serviços domésticos: a dificuldade de encontrar
profissionais confiáveis e avaliar a qualidade do serviço antes da
contratação.

O Reparos+ busca centralizar essas informações em uma única plataforma,
permitindo que o usuário encontre profissionais, consulte seus perfis,
compare avaliações e entre em contato antes de contratar.

## 🎯 Objetivo

Facilitar a conexão entre clientes e profissionais de serviços domésticos,
oferecendo informações que auxiliem na escolha de um profissional.

## 🚀 Funcionalidades do MVP

- Busca de profissionais por especialidade e bairro
- Perfil profissional
- Avaliações por diferentes critérios
- Portfólio de serviços
- Certificações verificadas
- Chat interno
- Solicitação de contratação
- Simulação de pagamento
- Sistema de denúncia
- Interface responsiva

## ⭐ Sistema de avaliação

O profissional pode ser avaliado em quatro critérios:

- Qualidade
- Pontualidade
- Atendimento
- Orçamento

Essa abordagem busca apresentar uma avaliação mais completa do que
apenas uma nota geral.

## 🧑‍💻 Tecnologias

- HTML5
- CSS3
- JavaScript
- Interface responsiva
- Git e GitHub

## 🎨 Identidade visual

A identidade visual do Reparos+ utiliza uma combinação de:

- 🔵 Azul-marinho — identidade e confiança
- 🟠 Laranja — ações e chamadas para ação
- 🟡 Amarelo/dourado — avaliações e destaques
- ⚪ Tons neutros — fundos e organização da interface
